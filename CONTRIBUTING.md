# Contributing

- First create a branch (or fork). 
- Propose changes by pull request against `main`. Prof Muaaz Bhamjee approves all merges.
- Keep UK English and no em dashes throughout.
- Every external link added must be one you have opened; note the date you checked it in the PR description.
- Add a new venue to `templates/README.md` only with its official template link, its DHET or indexing status, and the date checked.
- Do not commit manuscripts, data or anything under review to this repository. It is for guidance and templates only; each paper lives in its own repository or Overleaf project.
- Do not commit restricted, personal or third-party confidential material (POPIA, ATLAS Collaboration, industry partners).
